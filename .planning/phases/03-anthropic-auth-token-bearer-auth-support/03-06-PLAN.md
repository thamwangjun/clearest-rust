<objective>
Remove `use_bearer_auth` as a configurable settings.json field and simplify the Anthropic auth resolver to two clean credential paths: ANTHROPIC_AUTH_TOKEN (bearer) and ANTHROPIC_API_KEY / settings api_key (x-api-key). Unknown fields in ProviderConfig (including the removed `use_bearer_auth`) become hard parse errors.

Purpose: The UAT showed that the `use_bearer_auth` pin adds complexity without user value — env vars alone provide unambiguous credential routing. Removing the field simplifies the resolver, eliminates dead conflict branches, and makes misconfigured settings files fail loudly rather than silently.

Output:
- `crates/core/src/lib.rs` — ProviderConfig with `deny_unknown_fields`, resolver with 2 conflict checks and 2 credential priorities
- `crates/core/tests/bearer_auth.rs` — 4 obsolete tests deleted, 1 new conflict test added, all remaining tests pass
</objective>

```rust
pub async fn resolve_anthropic_auth_async(&self) -> anyhow::Result<Option<(String, bool)>> {
    let provider_cfg = self.provider_configs.get("anthropic");

    let env_api_key = std::env::var("ANTHROPIC_API_KEY")
        .ok()
        .filter(|v| !v.is_empty());
    let env_auth_token = std::env::var("ANTHROPIC_AUTH_TOKEN")
        .ok()
        .filter(|v| !v.is_empty());
    let provider_api_key = provider_cfg
        .and_then(|p| p.api_key.as_deref())
        .filter(|s| !s.is_empty());
    let top_level_api_key = self.api_key
        .as_deref()
        .filter(|s| !s.is_empty());

    // D-02 condition 1: both env vars set → conflict error (unchanged)
    if env_api_key.is_some() && env_auth_token.is_some() {
        anyhow::bail!(
            "ANTHROPIC_API_KEY and ANTHROPIC_AUTH_TOKEN are both set; \
             these are mutually exclusive (x-api-key vs Bearer auth). \
             Unset one to continue."
        );
    }
    // D-02 condition 4: top-level Config.api_key + ANTHROPIC_AUTH_TOKEN → conflict error (unchanged)
    if top_level_api_key.is_some() && env_auth_token.is_some() {
        anyhow::bail!(
            "Config api_key and ANTHROPIC_AUTH_TOKEN are both set; \
             these are mutually exclusive (x-api-key vs Bearer auth). \
             Unset one to continue."
        );
    }
    // D-02 condition 5 (NEW): provider_api_key in settings + ANTHROPIC_AUTH_TOKEN → conflict error
    if provider_api_key.is_some() && env_auth_token.is_some() {
        anyhow::bail!(
            "anthropic.api_key in settings and ANTHROPIC_AUTH_TOKEN are both set; \
             these are mutually exclusive. Remove one to continue."
        );
    }

    // Priority 1 (NEW): ANTHROPIC_AUTH_TOKEN env — bearer path, checked before x-api-key
    if let Some(t) = env_auth_token {
        return Ok(Some((t, true)));
    }
    // Priority 2: x-api-key path (provider_configs.api_key → ANTHROPIC_API_KEY env → top-level api_key)
    if let Some(key) = self.resolve_anthropic_api_key() {
        return Ok(Some((key, false)));
    }
    // Priority 3 (OAuth — unchanged): …
}
```
