| settings.json config.env → process env | Values from user-writable file are injected into process env; real env vars always win |
| Conflict error → terminal output | Err propagated via ? prints to stderr via anyhow's Display — no credential values in the message |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-03-01 | Spoofing | config.env injection overriding process env | mitigate | Injection uses `if std::env::var(key).is_err()` — only sets vars that are NOT already in the process env; real env vars always win |
| T-03-03-02 | Information Disclosure | Conflict error printed to terminal | accept | Error message names env var names and config key paths only (no values); necessary for usability |
| T-03-03-03 | Denial of Service | Malformed settings.json config.env causing crash | accept | `config.env` is `HashMap<String, String>` — serde will fail to deserialize malformed JSON before this code runs; existing startup error handling covers it |
</threat_model>
